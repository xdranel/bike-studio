# Bike Studio

is a web application for....



Buat kalian member team 

Untuk sekarang biar ada namamu di contributors ada 2 cara baca dulu!!!

Cara 1:
- git clone https://github.com/xdranel/bike-studio
- Edit README.md masukan nama dan dan link github mu pada bagian author
- git add README.md
- git commit -m "first commit"
- git push -u origin main

Cara 2: Jika terjadi error permission
- git remote -v => output https://github.com/xdranel/bike-studio.git
- gh auth status => jika tidak ada install https://cli.github.com/ sesuai OS
- gh auth login
- gh auth setup-git
- git push origin main

## Developing Stage

sangat di mohon untuk per-member membuat branch untuk dirinya sendiri jangan pernah push di "origin main"!!!!  
kita ga usah bikin branch per-feature tetapi per backend/frontend jika memang ada perubahan pada 2 folder itu  

misal:  
backend-haidar
frontend-arka

jadi langkahnya:
- git checkout -b backend-nama
- git add apa saja yang di add
- git commit -m "pesan" (untuk message commit convention bisa di cek pada https://www.conventionalcommits.org/en/v1.0.0/)
- git push -u origin namabranch

JANGAN LUPA Sebelum push ngomong o cik di grup, biar gk conflict biar pada pull atau fetch biar pada merge di local
